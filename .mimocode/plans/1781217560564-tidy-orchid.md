# Plano: Conteúdo Multi-idioma (Bíblia, Catecismo, Diretório, Jornadas Sacramentais)

## Objetivo

Adicionar suporte a múltiplos idiomas (`pt-BR`, `en`, `es`) para:
- Bíblia Católica
- Catecismo de São Pio X
- Diretório Geral para a Catequese (Santa Sé, 1997)
- Modelos de Jornada Sacramental

Disponível em homologação, produção e localhost.

## 2. Script de Importação de Dados Externos

### 2.1 Bíblia Católica (en, es)

Criar `src/server/scripts/importBible.ts` — script standalone que:
- Usa a API pública gratuita [getbible.net](https://getbible.net/) ou [bible-api.com](https://bible-api.com/)
- Para cada idioma (`en`, `es`), importa os 73 livros do cânon católico
- Exemplo de endpoint: `https://bible-api.com/john+3:16?translation=kjv`
- **Inglês**: Douay-Rheims (tradicional católica) — disponível via bible-api
- **Espanhol**: Biblia de Jerusalén ou Reina-Valera — disponível via APIs públicas
- Gera ficheiros JSON intermédios em `src/server/data/bible_en.json`, `bible_es.json`
- Também gera `bible_pt.json` a partir dos dados já existentes na BD (Figueiredo)
- O script é idempotente: só importa se não existirem versículos com aquele locale

### 2.2 Diretório Geral para a Catequese

Criar `src/server/scripts/importDirectory.ts` — faz web scraping do site do Vaticano:
- **pt-BR**: `https://www.vatican.va/roman_curia/congregations/cclergy/documents/rc_con_ccatheduc_doc_17041998_directory-for-catechesis_po.html`
- **en**: `https://www.vatican.va/roman_curia/congregations/cclergy/documents/rc_con_ccatheduc_doc_17041998_directory-for-catechesis_en.html`
- **es**: `https://www.vatican.va/roman_curia/congregations/cclergy/documents/rc_con_ccatheduc_doc_17041998_directory-for-catechesis_sp.html`
- Extrai parágrafos numerados, partes/Introdução, capítulos
- Guarda em JSON intermédio: `src/server/data/directory_pt.json`, `directory_en.json`, `directory_es.json`
- Idempotente: verifica `DirectoryEntry.count({ where: { locale } })`

### 2.3 Catecismo de São Pio X (en, es)

Atualizar `src/server/scripts/bibleCatechismSeed.ts`:
- **Inglês**: Catechism of St. Pius X — disponível em https://www.ewtn.com/catholicism/library/catechism-of-st-pius-x-1286 (web scraping ou JSON manual)
- **Espanhol**: Catecismo de San Pío X — disponível em várias fontes online
- Criar ficheiros JSON intermédios: `src/server/data/catechism_en.json`, `catechism_es.json`

### 2.4 Modelos de Jornada Sacramental

Atualizar `src/server/scripts/journeyTemplateSeed.ts`:
- Os 5 templates existem em pt-BR
- Criar versões traduzidas para en e es com os mesmos milestones (nomes/descrições traduzidos)
- Ficheiro JSON intermédio com todas as traduções: `src/server/data/journeyTemplates.json`

## 8. Notas / Riscos

- **Bíblia completa**: ~31K versículos × 3 idiomas ≈ 93K linhas. O seed será lento. Considerar seed parcial (apenas Génesis/Evangelhos) para dev, com importação completa para homolog/prod.
- **Scraping do Vaticano**: O site pode mudar estrutura HTML. Os scripts de scraping devem ser robustos com fallbacks.
- **APIs externas**: A disponibilidade da bible-api.com não é garantida. Considerar fallback para ficheiros JSON estáticos.
- **Migração Prisma**: Usar SEMPRE `wasp db migrate-dev`, nunca Prisma CLI nativo (risco de dropar tabelas Auth/Identity).
