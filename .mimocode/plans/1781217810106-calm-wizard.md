# Plano: Configurar Google Tag Manager

## Objetivo
Injetar os dois snippets do GTM (`GTM-MTGNTJG6`) na aplicação:
1. Script `<script>` no `<head>` — para carregar o GTM com prioridade
2. `<noscript>` `<iframe>` logo após `<body>` — fallback para browsers sem JS

## Abordagem

### 1. Script no `<head>` → `main.wasp:30`
O Wasp tem um campo `head` no bloco `app` que injeta HTML direto no `<head>`. Adicionar o snippet GTM como uma string no array `head`, após as entradas existentes (linha 30):

```wasp
"<!-- Google Tag Manager -->",
"<script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src='https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);})(window,document,'script','dataLayer','GTM-MTGNTJG6');</script>",
"<!-- End Google Tag Manager -->",
```

### 2. `<noscript>` no `<body>` → `vite.config.ts`
O Wasp **não** tem campo `body` no `main.wasp`. A solução é um plugin Vite com `transformIndexHtml` que injeta o `<noscript>` logo após a abertura do `<body>`:

- Criar função `gtmNoScriptPlugin()` que usa `transformIndexHtml` para substituir `<body>` por `<body>\n<noscript>...</noscript>`
- Adicionar ao array `plugins` em `defineConfig`

```ts
function gtmNoScriptPlugin(): Plugin {
  return {
    name: 'inject-gtm-noscript',
    transformIndexHtml(html) {
      const gtmId = 'GTM-MTGNTJG6';
      return html.replace(
        '<body>',
        `<body>\n<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=${gtmId}"\nheight="0" width="0" style="display:none;visibility:hidden"></iframe></noscript>`
      );
    },
  };
}
```

E adicionar `gtmNoScriptPlugin()` ao array de plugins.

## Ficheiros a modificar
- `app/main.wasp` — adicionar script GTM ao `head` array
- `app/vite.config.ts` — adicionar plugin Vite para o `<noscript>` GTM

## Verificação
1. `wasp compile` — garantir que compila sem erros
2. `wasp start` — abrir o browser, inspecionar o HTML source e confirmar que:
   - O script GTM aparece no `<head>`
   - O `<noscript>` iframe aparece logo após `<body>`
3. Verificar no Google Tag Manager que o container está a receber hits (usar modo Preview)
