# Limpar npm cache e Playwright

## Passos
1. `npm cache clean --force` — remove ~1.7G do cache npm
2. Remover diretórios do Playwright: `rm -rf ~/.cache/ms-playwright/ ~/.cache/ms-playwright-go/` — libera ~1G

## Verificação
Após limpar, confirmar espaço libertado com `du -sh ~/.npm ~/.cache/ms-playwright ~/.cache/ms-playwright-go 2>/dev/null`
