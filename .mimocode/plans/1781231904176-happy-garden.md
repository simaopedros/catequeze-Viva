# Plano: Correção de i18n — Textos Fixos e Traduções Faltando

## Escopo

Foram encontrados **três tipos de problemas** na aplicação:

1. **Ficheiros sem `useTranslation`** — todo o texto está hardcoded em pt-BR (alto impacto: login, signup, 2FA, modais)

3. **25 chaves de tradução em falta** — usadas em `t()` mas ausentes dos JSONs em todos os 3 locales

## Notas de Implementação

1. **Namespaces**: Criar namespace `auth` (novo) para login/signup/2FA. Reutilizar namespaces existentes (`common`, `family`, `components`, `parishes`, `ai`, `meetings`, `landing*`) onde possível.

2. **Padrão de chaves**: Seguir o snake_case já usado no projeto (ex: `login_title`, `signup_subtitle`, `error_fill_all`).

3. **Fallback para pt-BR**: Após adicionar chaves aos JSONs, remover os fallbacks `|| '...'` pois o `fallbackLng` já é `pt-BR`.

4. **Após cada fase**, correr:
   ```bash
   npm run i18n:build && npm run i18n:check
   ```
   Para regenerar `resources.ts` e validar paridade de chaves.

5. **Testar**: `npm run test:unit` (inclui testes de i18n), `npm run lint`.
