# Plano: Co-Criação Colaborativa de Encontros (IA + Catequista)

## Resumo

Transformar o **Gerador Inteligente de Encontros** (AIPlannerPage) de um wizard linear de 3 passos para um **espaço de trabalho split-screen interativo** com chat IA em tempo real (streaming SSE), editor de blocos, integração de fontes (Bíblia/CIC/DGC), histórico de versões, e 3 recursos extras (slider de profundidade teológica, histórias de santos, ganchos pedagógicos).

---

## Escopo

### Incluído (Fase Única)
- Layout split-screen (painel esquerdo: chat IA + contexto, painel direito: editor de blocos do encontro)
- Chat interativo com streaming via SSE
- Geração inicial rápida (idade + tema) e refinamento contínuo via chat
- Prateleira de Contexto (Bible/CIC/DGC) com busca integrada
- Editor de blocos do encontro com streaming inline por bloco
- Controle de versões (ContentVersion) com diff e restauro
- Sugestões inteligentes da IA (cards)
- Slider de profundidade teológica
- Injetor de histórias de santos
- Prateleira de ganchos pedagógicos
- Modelo de créditos: 1 crédito por sessão colaborativa

### Excluído (Fases Futuras)
- Extração de transcrições do YouTube
- Drag-and-drop de blocos (DND)
- Gerador de quizzes inline
- Sugestor litúrgico de cantos com player
- Designer de folheto PDF (handout)
- Simulador de ritmo e alocador de tempo
- Filtro de adaptabilidade neurodivergente
- Tradutor litúrgico e adaptador cultural

## Arquitetura

### 1. Novos Modelos de Dados (`schema.prisma`)

```prisma
model CollaborativeSession {
  id             String             @id @default(uuid())
  createdAt      DateTime           @default(now())
  updatedAt      DateTime           @updatedAt

  contentItemId  String             @unique
  contentItem    ContentItem        @relation(fields: [contentItemId], references: [id], onDelete: Cascade)

  createdById    String?
  createdBy      User?              @relation(fields: [createdById], references: [id])

  locale         String             @default("pt-BR")

  messages       SessionMessage[]
  attachments    ContextAttachment[]
}

model SessionMessage {
  id        String               @id @default(uuid())
  createdAt DateTime             @default(now())
  role      String               // "user" | "assistant" | "system"
  content   String

  sessionId String
  session   CollaborativeSession @relation(fields: [sessionId], references: [id], onDelete: Cascade)
}

model ContextAttachment {
  id        String               @id @default(uuid())
  createdAt DateTime             @default(now())
  type      String               // "BIBLE_REF" | "CATECHISM_REF" | "DIRECTORY_REF" | "TEXT"
  title     String
  sourceUrl String?
  payload   String               // Texto da passagem bíblica, CIC, ou Diretório

  sessionId String
  session   CollaborativeSession @relation(fields: [sessionId], references: [id], onDelete: Cascade)
}
```

### 2. Novas Operações (main.wasp)

| Operação | Tipo | Descrição |
|----------|------|-----------|
| `startCollaborativeSession` | action | Cria sessão + ContentItem inicial, consome 1 crédito. Gera estrutura base com streaming SSE. |
| `sendCollaborativeMessage` | API (SSE) | Envia mensagem no chat, retorna resposta em streaming. POST /api/collaborative-chat-stream |
| `generateBlockStream` | API (SSE) | Gera/regenera um bloco específico via streaming. POST /api/generate-block-stream |
| `getSessionHistory` | query | Retorna mensagens do chat da sessão |
| `addContextAttachment` | action | Adiciona fonte (Bíblia/CIC/DGC) à prateleira de contexto |
| `removeContextAttachment` | action | Remove fonte do contexto |
| `saveContentVersion` | action | Salva snapshot do ContentItem como ContentVersion |
| `getContentVersions` | query | Lista versões do ContentItem |
| `restoreContentVersion` | action | Restaura ContentItem para uma versão específica |
| `getAiSuggestions` | query | Retorna cards de sugestão da IA com base no estado atual |
| `getSaintStory` | query | Busca história de santo relevante ao tema |
| `getPedagogicalHooks` | query | Sugere ganchos pedagógicos para o tema |
| `adjustTheologicalDepth` | API (SSE) | Re-gera blocos com nova profundidade teológica via streaming |

## Detalhes de Implementação

### Fluxo de Créditos
1. `startCollaborativeSession` chama `assertAndDeductCredits` com 1 crédito
2. A sessão fica ativa por 24h (campo `updatedAt` na `CollaborativeSession`)
3. Se o usuário voltar a uma sessão existente (dentro de 24h), não cobra novo crédito
4. Após 24h, reabrir a sessão cobra +1 crédito

### Streaming SSE (Padrão)
Seguir o padrão de `chatStream.ts`:
```typescript
res.writeHead(200, {
  'Content-Type': 'text/event-stream',
  'Cache-Control': 'no-cache',
  'Connection': 'keep-alive',
  'X-Accel-Buffering': 'no',
});
// ... streaming loop
res.write(`data: ${JSON.stringify({ chunk })}\n\n`);
res.write(`data: ${JSON.stringify({ done: true, blockField?, contentItemId? })}\n\n`);
```

### Contexto do Chat (System Prompt Dinâmico)
O system prompt do chat colaborativo é montado dinamicamente:
```
${THEOLOGICAL_SYSTEM_PROMPT}
${COLLABORATIVE_SYSTEM_PROMPT}

ESTADO ATUAL DO ENCONTRO:
- Título: ${contentItem.title}
- Tema: ${contentItem.theme}
- Objetivo: ${contentItem.pastoralObjective}
- Conteúdo Central: ${contentItem.mainContent}
...

FONTES DE CONTEXTO ANEXADAS:
[BIBLE_REF] ${att.title}: ${att.payload}
[CATECHISM_REF] CIC §${att.title}: ${att.payload}
...
```

### Blocos do Encontro
Mapeamento dos campos do `ContentItem` para blocos visuais:
| Campo | Bloco | Ícone |
|-------|-------|-------|
| `title` | Título | `BookOpen` |
| `pastoralObjective` | Objetivo Pastoral | `Target` |
| `openingPrayer` | Oração Inicial | `Heart` |
| `biblicalReading.reference` + `biblicalReading.text` + `biblicalReading.explanation` | Palavra de Deus | `BookOpen` |
| `mainContent` | Conteúdo Central | `ScrollText` |
| `dynamic` | Dinâmica | `Users` |
| `familyTask` | Compromisso Familiar | `Home` |
| `closingPrayer` | Oração Final | `Heart` |
| `estimatedTime` | Duração Total | `Clock` |

### Comandos Rápidos no Chat
- `[CIC 1324]` → busca parágrafo do Catecismo e adiciona como contexto
- `/biblia Jo 15,1-8` → busca passagem bíblica e adiciona como contexto
- `/dgc 145` → busca parágrafo do Diretório e adiciona como contexto
- `/refinar [bloco]` → direciona o prompt para refinar um bloco específico
- `/santo` → atalho para injetor de história de santo
- `/gancho` → atalho para prateleira de ganchos
