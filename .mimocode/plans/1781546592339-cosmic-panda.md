# Plano: Reorganização das Funcionalidades de IA

## Situação Atual

O ecossistema de IA tem **4 interfaces de chat** e **2 fluxos de geração de encontros** redundantes, com **3 links no sidebar**, causando confusão.

| Recurso | Localização atual | Backend | Problema |
|---|---|---|---|
| AI Planner | `/app/ai-planner` (wizard 3 passos) | `generateMeetingWithAi` | Redundante com Collaborative |
| Collaborative Planner | `/app/collaborative-planner` (workspace) | `startCollaborativeSession` | Escolha confusa para o usuário |
| My AI Generations | `/app/my-ai-generations` (lista) | `listMyAiGenerations` | É filtro da Content Library |
| Chat flutuante | AIHelperWidget (todas as páginas) | `/api/chat-stream` | Stateless, não persiste |
| Chat no Messages | MessagesPage (ChatView) | `chatWithAi` | Separado do widget |
| Chat colaborativo | CoPilotPanel (dentro do planner) | `/api/collaborative-chat-stream` | Mais um chat |

---

## Objetivo

**1 link no sidebar → "Assistente IA", 1 fluxo de planner, 1 chat unificado, AI Generations na Content Library.**

## Fase 3: Unificar Chat de IA

### Problema atual

- `AIHelperWidget` → `/api/chat-stream` (stateless, sem histórico)
- `MessagesPage/ChatView` → `chatWithAi` action (persiste em Conversation/Message)
- `CollaborativeChat` → `/api/collaborative-chat-stream` (session-based, efêmero)
- Class/Community detail → `getOrCreateClassChat` (cria Conversation)

### Solução

**Manter 2 canais de chat**, com papéis claros:

#### A) Chat Teológico Geral (AIHelperWidget)
- Permanece como widget flutuante no canto inferior direito
- **Melhoria**: agora mostra histórico de conversas recentes (usa `listConversations` filtrando por tipo AI)
- **Melhoria**: permite continuar conversa anterior ou iniciar nova
- Backend: `/api/chat-stream` (já existente, stateless com cache)
- Opcionalmente persiste no sistema de Conversations quando usuário quer salvar

#### B) Chat no Contexto do Planner (CollaborativeChat)
- Permanece dentro do workspace colaborativo (CoPilotPanel > aba Chat)
- **Sem alterações** — já funciona bem para refinar conteúdo em tempo real
- Backend: `/api/collaborative-chat-stream` (já existente, session-based)

#### C) Mensagens entre usuários (MessagesPage)
- **Sem alterações** na funcionalidade de chat entre usuários
- Apenas remover/reorganizar referências a chat com IA que estejam misturadas

### Arquivos a modificar

**`src/catequese/components/AIHelperWidget.tsx`**
- Adicionar seletor de conversa (dropdown com conversas recentes de IA)
- Adicionar botão "Nova conversa"
- Adicionar botão "Salvar nos Mensagens" que persiste a conversa atual
- Manter feedback (thumbs up/down) existente

**`src/server/operations/chatStream.ts`**
- Adicionar suporte opcional a `conversationId` no body para persistir mensagens
- Se `conversationId` for enviado, salvar mensagens no sistema de Conversation/Message
